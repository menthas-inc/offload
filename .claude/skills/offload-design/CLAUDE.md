# Working preferences

- **Always open the file after writing it.** Every time the mobile kit is updated or a new exploration file is created, call `show_to_user` on it in the same turn. The user should never have to ask to see it.
- Never use em dashes anywhere.
- **Every exploration file gets the iOS / Android / Web platform switch** (sticky `.plat` pill at the top, choice persisted in localStorage), as in `explorations/today.html`.
