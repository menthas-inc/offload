# Applying the 5 September design decisions

Two steps: get the updated design system into the repository, then tell Claude Code what to do with it.

## 0. One file is shared, and it is merged rather than replaced

`decisions.md` is the only file both sides write. Everything else under
`.claude/skills/offload-design/` is the design system's, and the repository does not edit it: the
design guard hook skips that folder by name.

**The copy in this download is already merged**, as of 2026-09-05 19:17 UTC. It holds the three
entries the repository added today (the plate's corners, the conversation's exit, the swipe panel's
opacity) alongside the design side's own. If the repository has appended anything since that
timestamp, keep those entries and drop this file from the replace, or paste the newer entries back
in under `## Open`. Nothing else in the tree needs that care.

## 1. Update the checked-in design system

The repository carries this project at `.claude/skills/offload-design/`. Download the project, replace
that folder with it, and commit. Include the generated files, `_ds_bundle.js`, `_ds_manifest.json` and
`_adherence.oxlintrc.json`, so a fresh clone has a working bundle and lint config.

Then, in the repo:

```
pnpm tokens
```

Three token changes need it: `--duration-mark` (1400ms, the change mark), the `--breakpoint-*` family,
and the `[data-type="large"]` type scale. That last one means `apps/web` can stop defining its own
scale and read the tokens instead.

## 2b. Three things already carried back

The repository's own entries from today are applied here, so these are not open questions any more:

- **`SwipeRow` drives its reveal's opacity from the same value as its offset**, and the contract now
  says so. The general rule is in `readme.md`: hiding by stacking order is not hiding, and anything
  that must not appear carries its own opacity or is not mounted.
- **The plate's two states are written down**: it rounds its top only while nothing is stacked on it,
  and the keyboard clears it to the composer alone.
- **The conversation's exit is written down**: 280ms, the same curve both ways, travel equal to the
  sheet's own measured height, no fade, behind the bottom bar.
