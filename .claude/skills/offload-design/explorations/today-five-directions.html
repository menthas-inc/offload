Today: five directions

Today on main is the day-one invitation, the zone strip, and three groups of the thread page's own rows (Overdue, Today, Tomorrow). The kit's Today had more: people waiting on you, what moved in shared threads, the day's agenda with free time as a row, and a line of nudges. These five start from that and go further, from safe to wild. All five draw from what the app already knows, and all five are customised the same way: you describe the Today you want once, one model call turns it into a layout, and every open after that renders the layout with no model in the loop.

How customising works in every direction

compile once, render forever

1You say it

In words, in the Today sheet: "Work things first on weekdays. Keep Flat admin off Today until the weekend. Show my calendar before anything else in the morning." Or with the switches and handles, which write the same thing.

2One call compiles it

The words go to the model once, with the account's thread and label ids, and come back as a Today layout: a small, validated document of sections, order, filters and time rules. Anything it cannot express is refused in words, not guessed.

3You see what it understood

The layout is shown back as plain rules you can tap off one by one. Nothing is hidden behind the prompt, and a hand edit changes the layout directly without another call.

4Every open renders it

The server applies the layout to the agenda query. No model call per open. It recompiles only when you change the words, and a rule naming a thread that is deleted drops out with a line saying so.

{
  "version": 1,
  "sections": [
    { "kind": "calendar", "when": { "before": "10:00" }, "pin": "top" },
    { "kind": "waiting" },
    { "kind": "due", "order": ["overdue", "today", "tomorrow"],
      "sort": { "threadsFirst": ["thr_work", "thr_q4"], "on": "weekdays" } },
    { "kind": "moved", "only": "shared" },
    { "kind": "nudges", "max": 1 }
  ],
  "hide": [
    { "thread": "thr_flat", "until": "saturday" }
  ],
  "said": "Work things first on weekdays. Keep Flat admin off
           Today until the weekend. Calendar first in the morning."
}
The grammar is fixed and small, so a layout is always valid and always renders:
  • Sections from a closed set: waiting, due (overdue, today, tomorrow), calendar, moved, nudges, later this week.
  • Filters by thread, label, type, or person, by id.
  • Time rules: before or after an hour, weekdays or weekends, until a day.
  • Limits: how many in a section, whether it folds when empty.

Two things it never does: it never hides something overdue for longer than a day without saying so on Today, and it never hides a broken connection. Those are the product's promises, not preferences.

A. Tidy

safewhat's built, finished

The three groups on main, with the two things the kit had and the code lost: waiting on you on top, and one nudge slot above it. Every section is a card of the thread page's own rows. Customising is a sheet of sections with switches and handles, and a line to say it in words.

B. The day as a line

safefrom the kit's DayAgenda

One chronological line for today: calendar events and timed rows in order, a now line, and free time as a row, as the kit drew it. Untimed things due today sit in Anytime today under the line; overdue sits above it, because it is already late. People waiting and nudges come first. Reads like a day, not a list.

C. The brief

mediumoffload's voice, without a call per open

A paragraph at the top in Literata, written from templates, not generated: counts, the next event, who is waiting. Each underlined phrase is a way into its rows. Under it, the sections the brief summarised. The prompt shapes what the brief mentions and in what order, compiled like everything else.

D. One thing at a time

wilda deck, then the rest

The most timely thing is a card, with the one action that settles it: answer, tick, reconnect. Settle it or put it off and the next card comes up. Everything else is a quiet list below. For people who open Today to be told what to do next. The layout decides what counts as a card.

E. A Today you wrote

wildthe layout is the page

The compiled layout is not hidden in a sheet: it is the page's own structure, as sentences. Each clause heads the section it produced, and every token in it (a thread, a label, an hour) is tappable to change or drop, with no model call. Edit the words at the top and it recompiles. The most honest version of "customise with a prompt", and the most unusual.
