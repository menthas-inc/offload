Dark theme

Three ways to invert the same system. Each is shown on Today, a conversation, and Settings, since those three stress different things: rules and dense text, coloured chips against bubbles, and large filled containers.

All three keep the light theme untouched and swap only the semantic aliases, so components need no dark-specific code. Whichever you pick becomes a scope in tokens/colors.css that follows the system setting, with the manual override already stubbed in Settings > Appearance.
