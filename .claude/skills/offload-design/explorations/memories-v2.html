Memories tab

One tab, two views of the same memories, behind a List | Map switch beside the title, the way a thread switches to its map. List is A from last round. Map is D reworked: memories of one kind sit together, memories that mean similar things sit closer still, and you zoom and pan around it. Tapping a memory in either view opens the same editor. List and map

  • The switch is Segmented's icon variant, the same control a thread uses for List | Map. The view you pick is remembered on the device.
  • Zoom has two levels of detail. Out, each kind is one named cloud with its count, and memories are dots. In, the names give way to the sentences, which grow with the zoom. Kinds you have moved away from are pinned at the edge, so you can always find your way back.
  • Tap opens the editor sheet from the list, unchanged: text, kind, where it came from, Forget. On web it is the right-hand pane in both views.
  • Changing a memory's kind moves its dot to that cloud the next time the map is drawn.

Open questions

  • The map needs positions that mean something. 038 does not embed memories (Retrieval is out of scope). Grouping by meaning needs an embedding per memory, laid out once a night inside each kind's cloud, so the map is stable from day to day rather than reshuffled on every open.
  • Third person. Memories are stored as Their wife is Meera. and shown that way. Your wife is Meera would need a second-person copy written with each one.
  • Typing a memory is new. 038 only writes one from a turn, an answer or the nightly pass. A typed one would be origin stated, with the same refusals as asking. Can it be a rule? 038 lets only the person make one, and this is the person.
  • Editing a learned memory. Once you change one, it should probably become yours, so the nightly pass cannot replace it.
  • The tab is called Notes in both apps today, with the cloudy glyph. This renames it Memories and keeps the glyph.
