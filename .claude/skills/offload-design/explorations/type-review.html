Type review

Two faces, each with one job. Below: what they are, then each one shown in the context it will actually be read in.

Updated 11 August. The monospace face is gone, numerals are Instrument Sans with tabular-nums. The assistant voice is now upright Literata rather than Newsreader italic. Title-2 (21px) has been dropped from the scale. Both remaining faces are still unlicensed Google Fonts substitutes.

Part one · the roster

Aa Bb 123
Instrument Sans
--font-core · 400 / 500 / 600

A neutral grotesque with slightly narrow proportions and a tall x-height, so dense lists stay legible without shouting. It carries the entire interface.

Used for: everything you tap or scan, the wordmark, screen titles, row titles, labels, buttons, tab bar, section headers.

Aa Bb 123
Literata
--font-quiet · 400 / 500, upright

A screen-first serif with low contrast, sturdy strokes and a large x-height. Upright, so it reads at speed in a chat, it sounds like a person rather than a magazine.

Used for: the answer in Ask, empty states, occasional asides. Never a button, label, or row title.

length limit
Two sentences. Past that it stops feeling like an aside and starts feeling like a blog.

Literata is a first pass at this voice. Five alternative pairings sit in type-combos.html.

Resolved 11 August.
  1. Three faces → two. Mono dropped; numerals are Instrument Sans with tabular figures.
  2. Serif italic → upright. Italic is slower to read and tiring in a chat. Literata is the first pass; see type-combos.html for five alternatives.

  4. Title-2 (21px) dropped. Only the sheet header used it, and it sat too close to title-1 and title-3.
