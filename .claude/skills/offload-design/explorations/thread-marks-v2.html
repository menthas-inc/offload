Thread marks decided 3 October

Each thread gets a Lucide glyph and one of the ten label hues. The tile is that one hue washed with the prism texture's light and shade, placed differently for every thread, so the marks read as part of the same family as the plate and the gate. offload picks the glyph by matching words in the name, with no model call, and you change it from the mark itself. The first round, with emoji and colour-only, is explorations/thread-marks.html.

The mark

a wash of one hue

The hue at 20% on white, then the prism's oil-ground texture laid over it in luminosity mode, so it adds only light and shade and never a second colour. Where the texture sits, how large and at what angle, are seeded from the thread's name. The glyph is the hue taken darker. Same treatment at every size, from the 18px tile in a pill to 56px in the picker.

The thread's title row

as Thread.tsx's Bar draws it

The name is in the app bar and nowhere else. There is no heading in the scroll: main took it out on 20 September, so the mark joins the name in the bar rather than adding a header. Back, the mark, the name, then the tools the bar already carries: List | Map when the thread has a place, Group with labels while it has no labels, Share when it can be shared, Calendars when an account is connected, and More. With List | Map in the bar, labels and calendars go to the top of More, as now. The filter bar sits under it. Tapping the mark or the name opens Edit thread.

Everywhere a thread is named

Edit thread

name, icon and colour in one sheet

Rename thread and the icon picker are one sheet. It opens from the mark or the name in the bar, and from More, where Edit thread replaces Rename thread. The mark beside the name field previews every change; under it the seventy glyphs in one grid that scrolls inside the sheet, so the sheet keeps its height, then the ten hues. Save writes the name, glyph and hue as one edit with one Undo (Thread updated); Cancel drops all three. The name field is focused only when the sheet is opened from the name. On the web the same body opens as a popover from the mark or the name.

How offload picks, without a model

Each of the seventy glyphs carries a short list of words. When a thread is made or renamed by offload, the name's words are matched against them and the first hit wins; the hue is the one least used among your threads, ties broken by order. No match keeps lasso, in its own hue, so the colour still tells it apart. Once you have picked one by hand, a rename never changes it.
