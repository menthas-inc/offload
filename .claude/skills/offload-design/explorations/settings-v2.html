Settings, tightened v2

Every settings page on all three platforms, redrawn over the app as built on main, in direction B: each section opens with a glyph tile, a 17px heading and a caption where it needs one. Choices of a few show preview tiles. Four additions, tagged new where they are not in the app yet: connecting by email on My people, See the tutorial again in Help, and on Connected apps, Calendar's Ask before adding and Mail's address with Copy on the app cards. Browser, Photos and What offload may do are gone.

What is wrong now

read from the code
  • Section labels are smaller than the rows they head. Group draws its label at 12px medium tertiary over 15px rows, on every page and every platform. It reads as a caption, not a heading, so pages read as one long list.
  • Signed in on says "Nothing else" when it failed. listSignedIn errors are caught as an empty list, and an empty list draws "Nothing else". The current device is in that list when it works, so an empty list only ever means the read failed.
  • Country on web is a native select in settingsValue: no color-scheme, so in dark the closed control keeps the browser's white field with light grey text. Time zone has the same control and the same problem.
  • My people has no way in. Connecting only starts from a thread's Share sheet; the page lists Connected (empty for most), Pending only if any, and Blocked. On day one it is a sentence and a Blocked row.
  • Connected apps is four labelled groups of one row each, two of them things that are not built and one a paragraph about what offload may do.
  • Week starts on and Theme on web are a bare segmented control under an h2, the only choice controls in the product that show nothing of what they choose.

Every page

direction B

Everything not tagged new is the build's copy, restructured. On web the index pane stays beside every page, as it does now, and the page head carries a one-line summary in the subtitle slot it already has.

Choosing one of a few

Theme, Week starts on, Text size

Preview tiles replace the bare segmented control: a light and a dark screen for Theme, the week with its first day filled for Week starts on, two sizes of Aa for Text size on web. The selected tile takes a 2px ink ring and a filled radio; on Android, the tonal blue container.

Country and Time zone on web

light and dark

A styled combobox replaces the native select: a field showing the value, opening a popover with a filter on top, Not set first and always reachable, a check on the current one. It is the phones' picker page as a popover. Both themes draw from tokens, so dark is not a special case. The phones keep their pushed picker page; its Now value becomes a check, matching this.

Signed in on, every state

My account

This device is always the first row, drawn from the session already held, so the list is never empty. Others list under it with End. A failed read says so beside Try again rather than claiming there is nothing.
