Then the real Google account: the consent screen with the sharing-list scope, 93 events synced, the participant counts read (1 and 3, null for the read-only holidays calendar), a real event on the rail, three test events written to the primary calendar and cancelled through `find_events` and `delete_event`.

Found and fixed: the calendar glyph on the phones drew as two pegs and a line since 012, because the icon generator read rect attributes in a fixed order and the design's `calendar.svg` has them in another, so the frame was dropped; the generator reads by name now and refuses a file whose drawable elements it did not all read. A grant Google refused at the write itself escaped as a 500 and left the connection active; it marks and refuses now. Connected apps kept saying `On` after a disconnect one level down; it reloads on focus. The model, refused `no_time`, filed an appointment a second time to give it a time; `edit_content` takes a time now and the prompt says one appointment is one row.

Not done on the device: Undo of a written event within its eight seconds, which adb cannot tap in time; the API test covers it. The LLM evals for principle 08 have not been run.
