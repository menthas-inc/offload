Ordered. Each cites the acceptance criteria it serves and the principles it satisfies. **Every task starts with its test, run and seen red for the reason the task exists, then the code that turns it green (QUAL-1).** Anything under `docs/tech/`, `docs/constitution/` or `.claude/skills/offload-design/` is written on `main`, never in the feature worktree.
