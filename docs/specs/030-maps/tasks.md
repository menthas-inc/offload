## 1. Server

- [ ] **T1.2** `places/query.ts`. Tests: trims, collapses, strips control characters; refuses a newline, 121 characters, a digit anywhere (*Rua Augusta 12*, *Terminal 2*, *1000-001*), an `@`, `https://`, `www.`, a possessive with either apostrophe (*Ana's*, *Ana’s*), and each no-place word whole but not inside a name (*Zoomarine* passes); `queryKey` differs with a different pepper and is stable for case and spacing. *(AC-5, AC-6, AC-7, AC-8)*
- [ ] **T1.3** `places/google.ts` on the T0.4 captures with a stub `fetch`. - [ ] **T1.5** `attachPagePoint`. Tests: finite in-range coordinates attach a `page` place keyed on five decimals; `0,0`, NaN, `1e999` and out-of-range are refused; two links with the same rounded point share one place. *(AC-2)*
- [ ] **T1.6** `places/refresh.ts`.
